# 📚 Library Management System

A simple **Library Management System** developed in **Java** using **Object-Oriented Programming (OOP)** concepts. This is a console-based application that allows users to manage books and library users through a menu-driven interface.

---

## 📌 Objective

To develop a mini Library Management System that demonstrates the use of Java OOP concepts such as Classes, Objects, Encapsulation, Constructors, and ArrayList.

---

## 🛠️ Tech Stack

- Java
- VS Code
- Terminal / Command Prompt
- JDK 17 or above

---

## 📂 Project Structure

```
LibraryManagementSystem/
│── Book.java
│── User.java
│── Library.java
│── Main.java
└── README.md
```

---

## ✨ Features

- ➕ Add New Book
- 📖 View All Books
- 👤 Add New User
- 👥 View All Users
- 📚 Issue Book
- 🔄 Return Book
- 🔍 Search Book by ID
- ❌ Exit Application

---

## 🧱 Classes Used

### Book.java
Stores book details:
- Book ID
- Title
- Author
- Issue Status

### User.java
Stores user details:
- User ID
- User Name

### Library.java
Manages all library operations:
- Add Book
- View Books
- Add User
- View Users
- Issue Book
- Return Book
- Search Book

### Main.java
Contains the menu-driven program and user interaction.
