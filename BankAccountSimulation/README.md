# Bank Account Simulation (Java OOP)

## Objective
Simulate basic bank operations using Java Object-Oriented Programming (OOP).

## Tools Used
- Java
- VS Code
- Terminal

## Features
- Create Bank Account
- Deposit Money
- Withdraw Money
- Check Balance
- View Transaction History
- Input Validation

## Project Structure

```
BankSimulation/
│── Account.java
│── BankApp.java
└── README.md
```

## OOP Concepts Used
- Class & Object
- Constructor
- Encapsulation
- Methods
- ArrayList
- Menu-driven Program

## How to Run

### Compile
```bash
javac Account.java BankApp.java
```

### Run
```bash
java BankApp
```

## Sample Operations
- Deposit
- Withdraw
- Check Balance
- Transaction History

## Learning Outcome
This project demonstrates Java OOP fundamentals by simulating common banking operations while maintaining account balance and transaction history.
