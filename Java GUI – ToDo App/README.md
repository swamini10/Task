# To-Do List Application (Java Swing)

## Objective
Build a desktop To-Do List application using Java Swing.

## Tools Used
- Java
- Swing (Built-in)
- IntelliJ IDEA CE / Eclipse / VS Code

## Features
- Add Tasks
- Delete Selected Task
- Simple GUI
- Scrollable Task List
- Input Validation

## Project Structure

```
ToDoList/
│── ToDoApp.java
└── README.md
```

## Swing Components Used

- JFrame
- JPanel
- JTextField
- JButton
- JList
- DefaultListModel
- JScrollPane
- JOptionPane

## How to Run

### Compile
```bash
javac ToDoApp.java
```

### Run
```bash
java ToDoApp
```

## Learning Outcome

- Learn Java Swing GUI development
- Work with event handling using ActionListener
- Manage dynamic data using DefaultListModel
- Build a simple desktop application using OOP
